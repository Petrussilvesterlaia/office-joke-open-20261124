One original office joke, written for make.fun's "Make the AI Judge Laugh: the Office Joke Open" — a trust-fall exercise where nobody catches you and HR rebrands the bruise as a lesson in self-reliance. The program writes the joke to `/output/entry.txt` and checks it against the competition's own gate (one line, 1–200 characters, not blank) before it counts as done.

## Run it

```sh
python3 main.py
```

That writes the joke to `/output/entry.txt` and prints its character count.
